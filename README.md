# MyCAD

電気工事用の 2D 配線図を描くための、ブラウザで動く簡易 CAD です。
インストール不要で、`index.html` を開くか GitHub Pages で公開した URL を開けば使えます。

## できること（v0.1）

- 縮尺（1/20〜1/200）と用紙（A4〜A2、縦・横）、図枠と表題欄
- 線（壁の太線と細線）。連続して描け、長さを数値で入力できる
- 端点・中点・交点・グリッドへのスナップ、直交モード
- 電気記号：コンセント、スイッチ、照明、ブラケット、換気扇、テレビ端子、分電盤、電力量計
- 建具：片開き戸、引違い戸、引違い窓（壁に近づけると向きを合わせて吸着）
- 配線：天井隠ぺい、床隠ぺい、露出、地中埋設。電線本数の斜線
- 寸法線、文字
- レイヤーごとの表示・ロック（下絵／建物／電気／寸法／文字）
- 器具ごとに品番・資料 URL・メモを登録（資料はワンクリックで開ける）
- 用紙枠を動かして印刷範囲を決める → 印刷、または PDF に保存
- ファイルへの保存と読み込み（.mycad.json）。ブラウザ内にも自動で保存

## 操作

| 操作 | キー・マウス |
|---|---|
| 選択／線／配線／寸法／文字／用紙位置 | V / L / W / D / T / P |
| 拡大縮小 | ホイール |
| 画面の移動 | 中ボタンでドラッグ、または Space を押しながらドラッグ |
| 全体表示 | Home |
| 長さを指定 | 線を描いている途中で数字を打って Enter |
| 水平・垂直 | Shift を押す間だけ、または F8 で切り替え |
| スナップ／グリッドスナップ | F3 / F9 |
| 記号の回転／反転 | R / F |
| 確定・終了 | Enter、右クリック、Esc |
| 削除 | Delete |
| 元に戻す／やり直し | Ctrl+Z / Ctrl+Y |
| 保存／開く／印刷 | Ctrl+S / Ctrl+O / Ctrl+P |

## Google ドライブで使う

PC の Chrome または Edge なら、保存先に「Google ドライブ for desktop」のフォルダを選べば、
そのまま上書き保存できます。ほかの端末ではドライブからファイルを取り出して「開く」で読み込みます。

## GitHub Pages で公開する

リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save。
数分後に `https://<ユーザー名>.github.io/MyCAD/` で開けるようになります。
